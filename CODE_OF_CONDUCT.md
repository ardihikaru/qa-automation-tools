# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussions about
the work. Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behaviour privately to the maintainer via a
[GitHub Security Advisory](https://github.com/ardihikaru/qa-automation-tools/security/advisories/new)
or a direct message to [@ardihikaru](https://github.com/ardihikaru). Every report is reviewed and kept confidential.
